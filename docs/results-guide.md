# 선생님 화면(닉네임별 점수) 만들기

## ★ Apps Script 3판 (2026-11-09, 5차시용 칸 추가)
- 5차시(숫자 계곡)는 **힌트를 쓴 과제 수**와 **안내 문제 수**를 따로 보내요. 3판으로 바꾸면 시트 맨 뒤에 칸 3개(힌트 쓴 과제 · 안내 문제 · 기록 방식)가 생기고, 선생님 결과 페이지에 💡 숫자로 보여요.
- 바꾸는 방법은 아래 2판 때와 같아요: 코드 전체를 `docs/results-apps-script.gs`(3판)로 바꿔 붙여 넣기 → 저장 → **배포 관리 → 연필 → 버전: 새 버전 → 배포**.
- 바꾸지 않아도 학생 기록은 그대로 쌓여요. 이때도 힌트를 쓴 과제는 '처음에 틀린 문제' 칸에 "💡힌트 사용: …"으로 남아요.
- 예전 기록 줄과 1~4차시 기록은 그대로예요(새 칸은 빈칸).

## ★ 선생님 결과 페이지 (2026-11-05 새로 생김)
- 주소: https://cheeyolove.github.io/chinese-adventure-game/teacher.html
- 날짜·차시별로 닉네임 결과, 진행(미션 1~4), 처음 정답률, 별, 걸린 시간, 틀린 문제, **많이 틀린 문제 순위**를 보여 줘요. 30초마다 저절로 새로 고쳐요.
- **🔌 기록 연결 확인** 버튼: 시험 기록 한 줄을 보내고 시트에 잘 들어오는지 바로 알려 줘요.
- 이 페이지를 쓰려면 Apps Script를 **2판 코드**로 한 번 바꿔야 해요.
  1. Apps Script 화면에서 코드를 모두 지우고 `docs/results-apps-script.gs`(2판)를 전부 붙여 넣고 저장
  2. **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포** (주소는 그대로예요. '새 배포'를 누르면 주소가 바뀌니 주의!)
  3. 같은 화면에서 실행 사용자 **나**, 액세스 권한 **모든 사용자**인지 확인


- 학생은 게임을 처음 시작할 때 **닉네임**을 정해요. 닉네임은 그 기기에 저장돼요.
- 선생님은 **선생님 링크**(아래 6번에서 나오는 웹 앱 주소)를 열면 닉네임별 점수를 볼 수 있어요.
- 여러 기기의 결과를 한곳에 모으는 저장소로 선생님 Google 계정을 써요. 처음 한 번만 설정하면 이후에는 시트를 열 필요가 없어요.


판다 탐험대는 서버가 없어서, 학생 결과를 **선생님의 Google 시트**로 받도록 만들었어요.
한 번만 설정하면 돼요(약 10분). 학생 이름은 선생님 Google 드라이브에만 저장돼요.

## 결과가 기록되는 때
- **입장:** 학생이 탐험을 시작할 때
- **미션 성공:** 미션 1~4를 하나 끝낼 때마다
- **클리어:** 지역을 끝낼 때

**기록되는 내용**
- 시간, 이름, 차시
- 진행(예: 2/4), 처음에 맞힌 문제 수 / 푼 문제 수
- 처음에 틀린 문제와 정답
- 별, 걸린 시간, 레벨, 기기(PC/모바일)

> 학생은 반드시 **https://cheeyolove.github.io/chinese-adventure-game/** 링크로 들어와야 기록돼요.
> - Claude 게임 링크(claude.ai)는 보안 때문에 외부로 보내기가 막혀 있어서 기록되지 않아요.
> - 선생님 미리보기(주소 끝 `#preview`)도 기록하지 않아요.

## 1. 설정 (처음 한 번)

1. **Google 시트를 새로 만들어요.**
   - https://sheets.new 를 열어요(학교 또는 개인 Google 계정).
   - 왼쪽 위 제목을 `판다 탐험대 결과`로 바꿔요.
2. **Apps Script를 열어요.**
   - 위 메뉴에서 **확장 프로그램 → Apps Script**를 눌러요.
3. **코드를 붙여 넣어요.**
   - 원래 있던 `function myFunction() { }`을 모두 지워요.
   - `docs/results-apps-script.gs` 파일 내용을 **전부 복사해서 붙여 넣어요**.
   - 💾(저장) 버튼을 눌러요.
4. **웹 앱으로 배포해요.**
   - 오른쪽 위 **배포 → 새 배포**를 눌러요.
   - **유형 선택**(톱니바퀴) → **웹 앱**을 골라요.
   - 설명: `판다 결과` (아무거나)
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
     - 학생들이 로그인 없이 결과를 보내야 해서 꼭 이렇게 해야 해요.
   - **배포**를 눌러요.
5. **권한을 허용해요.**
   - "액세스 승인"에서 내 계정을 골라요.
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (안전하지 않음)으로 이동 → 허용**을 눌러요.
   - 선생님이 직접 만든 코드라서 괜찮아요.
6. **웹 앱 URL을 복사해요.**
   - `https://script.google.com/macros/s/……/exec` 모양이에요.
7. **이 주소(= 선생님 링크)를 Claude에게 보내 주세요.**
   - 제가 게임에 넣어서 바로 올려 드릴게요(1~2분 뒤 학생 링크에 반영).

## 2. 결과 보기
- **결과표:** 6번에서 복사한 웹 앱 주소를 선생님 브라우저에서 열어요.
  - 오늘 결과가 학생별 표로 보여요: 이름, 차시, 진행, 처음 정답(%), 별, 처음에 틀린 문제, 시작·완료 시간, 기기.
  - 새 결과는 **새로 고침(F5)**을 누르면 보여요.
  - 다른 날짜는 주소 끝에 `?day=2026-11-03`처럼 붙여요.
- **원본:** Google 시트의 **기록** 탭에 한 줄씩 쌓여요. 필터나 정렬로 자유롭게 볼 수 있어요.

## 3. 알아 두면 좋은 점
- 학생은 게임을 처음 시작할 때 이름을 써요(예: `김민준 3번`).
  - 같은 기기에서는 다시 묻지 않아요.
  - 바꾸려면 시작 화면 ⚙ 설정 → ✏️ 내 이름 바꾸기를 눌러요.
  - "이름 없이 할래요"를 누르면 `(이름 없음)`으로 기록돼요.
- 인터넷이 잠깐 끊기면 그 순간의 기록은 빠질 수 있어요. 게임에는 영향이 없어요.
- 누군가 주소를 알면 가짜 기록을 보낼 수는 있어요. 수업용 결과 확인 정도로 써 주세요.
- 학기가 끝나면 시트를 지워 학생 이름을 정리해 주세요.
- 코드를 고쳐서 다시 배포할 때는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 해야 주소가 그대로 유지돼요.

## 4. 시트 설정 전에도 쓸 수 있는 방법
- 지역을 클리어하면 결과 화면에 **이름, 차시, 처음 정답 수, 별, '다시 볼 문제(처음에 틀린 문제)'**가 나와요.
- 학생이 이 화면을 캡처해서 수업 채팅방에 올리면 바로 확인할 수 있어요.
