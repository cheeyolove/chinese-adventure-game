# 1지역 대나무 언덕 수정 초안 (승인 전 · 게임 미반영)

> 선생님 결정을 반영한 초안이에요. 승인해 주시면 이대로 게임에 넣을게요.
> - 谢谢와 再见은 넣어요.
> - 你们好와 同学们好는 빼요.
> - 麻·骂 뜻 문제는 그대로 둬요.
> - 경성 지도를 추가해요.

---

## 1. 단어 목록 (1지역 = 11/3 수업, 1~2차시)

| 구분 | 한자 | 병음 | 뜻 | 바뀐 점 |
|---|---|---|---|---|
| 성조 | 妈 · 麻 · 马 · 骂 | mā · má · mǎ · mà | 엄마 · 삼(식물), 저리다 · 말(동물) · 꾸짖다 | 그대로 |
| 나라 | 中国 | Zhōngguó | 중국 | 그대로 |
| 나라 | 汉语 | Hànyǔ | 중국어 | 그대로 |
| 인사 | 你好 | nǐ hǎo | 안녕(하세요) | 그대로 |
| 인사 | 老师好 | lǎoshī hǎo | 선생님, 안녕하세요 | 그대로 |

### 새 단어 카드 문구 (배움 노트·해설에 나옴)
- **谢谢 xièxie — 고마워요**
  - 설명: 고마울 때 하는 말이에요. 뒤의 xie는 성조 표시 없이 짧고 가볍게 읽어요(경성).
  - 상황 문제용: "친구가 선물을 줬을 때 하는 말은?"
- **再见 zàijiàn — 잘 가요, 안녕히 계세요**
  - 설명: 헤어질 때 하는 인사예요. 再 zài는 ‘다시’, 见 jiàn은 ‘만나다’라는 뜻이에요.
  - 상황 문제용: "친구와 헤어질 때 하는 인사는?"

## 2. 경성 지도

### 배움 노트 (성조 카드 4장 뒤에 경성 카드 1장 추가)
> **경성 (표시 없음)**
> 성조 표시가 없는 소리예요. **짧고 가볍게** 읽어요.
> 예: 谢谢 xiè**xie** — 뒤의 xie가 경성이에요.

### 경성 문제 (4개)

**N1. 이 소리에서 짧고 가볍게 읽는 글자는?**
- 보여 주는 말: 谢谢 xièxie
- 보기: ① 앞 글자 xiè ② **뒤 글자 xie (정답)** ③ 두 글자 모두 똑같이 세게
- 힌트: 성조 표시가 없는 쪽을 찾아보세요.
- 해설: xièxie의 뒤 글자 xie에는 성조 표시가 없어요. 이렇게 짧고 가볍게 읽는 소리를 경성이라고 해요.

**N2. 성조 표시가 없고 짧고 가볍게 읽는 소리를 무엇이라고 할까요?**
- 보기: ① **경성 (정답)** ② 1성 ③ 3성 ④ 4성
- 힌트: ‘가벼울 경(輕)’ 자를 써서 ○성이라고 해요.
- 해설: 성조 표시가 없는 소리는 경성이에요. 짧고 가볍게 읽어요. 예: 谢谢 xièxie

**N3. 경성은 어떻게 읽을까요?**
- 보기: ① **짧고 가볍게 (정답)** ② 높게 쭉 길게 ③ 내려갔다가 올라가게 ④ 높은 데서 뚝 떨어지게
- 힌트: 표시가 없으니 힘을 빼고 살짝!
- 해설: 경성은 짧고 가볍게 읽어요. ②는 1성, ③은 3성, ④는 4성이에요.

**N4. 경성이 들어 있는 말은 어느 것일까요?**
- 보기: ① **谢谢 xièxie (정답)** ② 中国 Zhōngguó ③ 汉语 Hànyǔ ④ 再见 zàijiàn
- 힌트: 성조 표시가 없는 글자가 있는 말을 찾아보세요.
- 해설: 谢谢 xièxie의 뒤 글자 xie에는 성조 표시가 없어요. 그래서 경성이에요.

> **제안 (수업자료 확인 필요)**
> 妈妈 māma(엄마)도 대표적인 경성 예시예요. 게임 해설에는 이미 "보통 妈妈 māma처럼 두 번 써요"라는 문장이 있어요.
> 다만 妈妈는 7차시 가족 단어라서, 수업에서 1차시에 같이 보여 주실 때만 예시에 넣을게요.

## 3. 게임 미션 구성 (몬스터 수는 그대로)

| 미션 | 이전 | 수정안 |
|---|---|---|
| ① 죽순 길 (4마리) | 성조 문제 4개 (성조 고르기·표시 찾기·뜻·소리 설명) | **그대로** (麻·骂 뜻 문제 유지) |
| ② 인사 숲 (일반 3 + 중간보스) | 你好·你们好·老师好·同学们好 | **你好·老师好·谢谢·再见** |
| 중간보스 대나무 수호 슬라임 (2문제) | 성조 1 + 인사 1 | **경성 1(N1~N4 중 하나) + 인사 1** |
| ③ 나라 숲 (4마리) | 中国·汉语·병음 기초 | 그대로 |
| ④ 숲의 수호자 (5문제) | 성조, 상황 인사, 你好 실제 소리, 뜻, 인사 고르기 | 성조, 상황 인사, 你好 실제 소리, **경성(N1~N4 중 하나)**, 인사 고르기 |

- 보스에서 빠지는 문제는 '뜻' 1문제예요. 뜻 문제는 미션 ①에 그대로 남아요.
- 인사 문제(뜻 고르기, 중국어 고르기, 읽는 법, 상황 고르기)의 보기는 승인된 6개 단어(你好·老师好·谢谢·再见·中国·汉语) 안에서만 나와요.

### 상황 고르기 문제 (보기 4개 모두 승인 단어)
| 문제 | 정답 |
|---|---|
| 친구를 만났을 때 하는 인사는? | 你好 nǐ hǎo |
| 선생님께 인사할 때는? | 老师好 lǎoshī hǎo |
| 친구가 선물을 줬을 때 하는 말은? | 谢谢 xièxie |
| 친구와 헤어질 때 하는 인사는? | 再见 zàijiàn |

- 보기는 위 4개 인사(你好 · 老师好 · 谢谢 · 再见)예요.

---

## 4. 같이 바뀌는 것
- 배움 노트 제목: "1차시 표현" → "1~2차시 표현"
- 출발 전 '오늘 배울 말' 카드: 你们好·同学们好를 빼고 谢谢·再见을 넣어요.
- 예전에 你们好·同学们好 카드를 모은 기록은 지우지 않아요. 화면에서만 안 보여요.
- 빠른 퀴즈(대나무 언덕)도 같은 단어로만 나와요.
