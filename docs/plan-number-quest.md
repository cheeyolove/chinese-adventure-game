# 5차시 숫자 계곡 미션형 개편 계획 (2026-11-05)

## 지금 구조 확인
- 모든 지역이 같은 엔진: `STAGES[id]` 데이터 + 공통 `update()`(이동·문·몬스터 충돌→퀴즈·동전) + `render()`.
- 진행: `run.ms[i]`(미션별 need/done) → `completeMission(i)` → 카드 화면 → 문(`gates`) 열림 → 마지막 문 통과 시 `stageClear()`.
- 문은 열리기 전에는 땅부터 하늘까지 막혀서 점프로 못 넘음 (모든 지역 공통).
- 저장: `save`(레벨·경험치·코인·카드·별·동전/몬스터 동전 기록 등). 상점·꾸미기 아이템은 아직 없음.
- 기존 숫자 계곡(v1): 1~10 객관식 몬스터 퀴즈. 원본은 `docs/backup/number-stage-v1.js`에 백업.

## 안전하게 바꾸는 방법
- `STAGES.number`에 `quest: true`를 주고, 몬스터 목록을 비움. 공통 엔진에는 `if (STAGE.quest)`일 때만 도는 갈래만 추가 → 1~4차시 코드 경로는 그대로.
- 미션 상태는 모두 `run.q`에 둠 → 홈에 다녀와도 이어서, 새로 고침하면 처음부터(보상은 저장 기록으로 막음).
- 미션 완료 = `missionStep(i)` 한 번(need 1) → 기존 카드·문 열기·결과·선생님 기록 흐름 재사용.
- 보상(코인·경험치)은 `save.questEver.number`에 미션 번호를 남겨 처음 한 번만. 사과에는 코인 없음.
- 스킬 칩은 이 지역에서만 숨김.
- 듣기 문제 없음(🔊 버튼은 참고용으로만). 정답 판정에 음성을 쓰지 않음.

## 미션 구성 (필수 4개)
1. **안경 판다와 사과나무** (조작·수집): 나무 三 번 흔들기 → 사과 五 개 줍기 → 보고. 카드 一~五.
2. **숫자 연구가 판다** (석판 퍼즐, 탭 순서): 11(안내) · 12~14 · 15~19 · 20(안내) · 30~50. 카드 六~十.
3. **배달 판다** (찾아서 운반): 二十一 → 三十五/四十八 → 六十二/九十九 상자 찾기. 힌트 "십의 자리 + 十 + 일의 자리".
4. **숫자 축제** (종합): 1~10 석판 운반 · 11~19 만들기 · 몇십 만들기 · 두 자리 상자 운반 → 친구 판다 등장 + "숫자 마스터!" → 마지막 문.

## 확인할 것
5차시만 바뀌었는지, NPC 대화, 흔들기 3번·사과 5개 판정, 보고해야 완료, 석판 정답, 11~99 조합, 상자 연결, 모든 미션 후에만 클리어, 보상 중복 방지, PC·모바일 조작, 1~4차시 회귀, 플레이 시간.
