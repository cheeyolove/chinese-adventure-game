## 1. 배경
- **누가:** 초등학교 3~4학년, 중국어를 처음 배우는 학생들
- **어떻게:** 실시간 화상 수업(PPT)으로 약 30분 숫자를 배운 뒤 각자 게임을 해요. 목표 플레이 시간은 5~8분이에요.
- **기기:** 학생 PC, 태블릿, 휴대폰이 섞여 있어요. 소리가 안 나오는 기기도 있어요.
- **게임 전체:** 「판다 탐험대」는 픽셀풍 판다가 오른쪽으로 걸어가는 횡스크롤 게임이에요. 1~4차시는 "몬스터에 닿으면 객관식 퀴즈 → 4구역 문을 차례로 열기" 방식이에요.
- **5차시만 다름:** 몬스터 없이 **NPC의 부탁을 받아 탐험·조작·수집·배달·퍼즐로 해결하는 미션형**으로 바꿨어요.
- **결과 기록:** 학생 결과(닉네임, 처음에 맞힌 수, 틀린 문제)는 선생님 Google 시트로 보내져요. 선생님은 결과 페이지에서 봐요.

## 2. 학습 목표
1. 一~十의 한자와 병음을 알아본다.
2. 十을 이용해 11~19를 만든다. (十 + 숫자)
3. 20, 30… 몇십을 만든다. (숫자 + 十, 20은 二十)
4. 규칙으로 21~99를 읽고 이해한다. (숫자 + 十 + 숫자)

99개를 외우는 게 아니라 **규칙을 이해**하는 게 핵심이에요.

| 숫자 | 한자 | 병음 |
|---|---|---|
| 1~10 | 一 二 三 四 五 六 七 八 九 十 | yī èr sān sì wǔ liù qī bā jiǔ shí |
| 11 / 15 | 十一 / 十五 | shí yī / shí wǔ |
| 20 / 30 | 二十 / 三十 | èr shí / sān shí |
| 21 / 35 / 99 | 二十一 / 三十五 / 九十九 | èr shí yī / sān shí wǔ / jiǔ shí jiǔ |

- 병음은 글자마다 띄어 써요. 十은 문장 속에서도 shí로 표기해요(선생님 기준).

## 3. 게임 구조 (맵 1개, 구역 4개, 필수 미션 4개)
```
[구역1 사과나무 언덕] ─돌문─ [구역2 석판 연구소] ─돌문─ [구역3 배달 골목] ─돌문─ [구역4 축제 광장] ─숫자의 문(클리어)
 안경 판다·사과나무          숫자 연구가 판다·석판 제단    배달 판다·상자 4개          축제 촌장 판다·석판/상자
```
- **흐름:** NPC에게 말 걸기 → 부탁 받기 → 탐험·조작 → NPC에게 보고 → 미션 완료 → 돌문 열림
- **돌문:** 열리기 전에는 땅부터 하늘까지 막혀 있어요. 점프나 동전 모으기로는 건너뛸 수 없어요.
- 모든 미션을 끝내야 마지막 「숫자의 문」이 열리고 클리어돼요.

### 미션 1 · 안경 판다와 사과나무 (조작·수집, 목표 ①)
- **부탁:** "사과나무를 **三 sān** 번 흔들고, 사과 **五 wǔ** 개를 가져다줘!" 한자와 병음을 크게 보여 줘요.
- **흔들기:** 나무 옆에서 E키, 또는 모바일의 큰 「🌳 흔들기」 버튼을 눌러요.
  - 흔들 때마다 "一 yī! 二 èr! 三 sān!"이 떠요.
  - **정확히 3번째**에 사과 8개가 떨어지고, 그 뒤에는 흔들 수 없어요.
- **줍기:** 사과에 닿으면 주워요. 주울 때마다 "一 yī … 五 wǔ"가 떠요.
  - **5개에서 멈추고** 나머지 3개는 그대로 남아요.
  - 사과로는 코인이 늘지 않아요.
- **보고:** 안경 판다에게 돌아가야 완료돼요. 덜 모은 채로 말을 걸면 진행 상황만 보여 줘요.
- **힌트(2단계):** ① 一 yī · 二 èr · 三 sān · 四 sì · 五 wǔ 세기 → ② 三 = 3, 五 = 5
  - 힌트를 누르기 전에는 숫자 뜻을 보여 주지 않아요.
- **완료:** 카드 一~五를 받아요.

### 미션 2 · 숫자 연구가 판다의 석판 퍼즐 (목표 ②③)
- **안내:** "十 shí은 10이에요. 十 뒤에 一 yī을 붙이면 十一 shí yī = 11!"
- **석판 제단:** 화면에 목표 숫자(예: **12**)가 나와요. 학생은 一~十 석판 10개(한자 + 병음)를 **탭해서 순서대로** 칸에 놓아요.
- **문제 5개:**
  - 11 (안내 문제: 다음에 누를 석판이 반짝여요)
  - 12~14 중 하나
  - 15~19 중 하나
  - 20 (안내 문제: "숫자를 十 앞에 놓으면 몇십")
  - 30·40·50 중 하나
- **판정:** 칸이 다 차면 자동으로 판정해요.
  - 맞으면: "✔ 十二 shí èr = 12 / 十(10) + 二(2) → 10 + 2"
  - 틀리면: 만든 숫자를 알려 줘요. 예) "二十은 20이에요. 다시 해 봐요! 💡 十(10) 뒤에 일의 자리 숫자를 붙여요" 그다음 칸이 비워지고 다시 해요.
  - 규칙에 맞지 않는 순서(一十, 十十 등)는 "숫자가 되지 않아요"로 알려 줘요.
- **조작 버튼:** ↩ 하나 지우기, 💡 힌트, 나중에 하기(진행은 유지). PC는 숫자키 1~9, 0=十도 돼요.
- **완료:** 5개를 다 만들고 연구가 판다에게 보고하면 끝이에요. 카드 六~十을 받아요.

### 미션 3 · 배달 판다 (찾아서 운반, 목표 ④)
- **부탁:** "**二十一 èr shí yī** 상자를 가져다줘!" 아라비아 숫자는 힌트를 누르기 전에는 안 보여요.
- **상자:** 맵 곳곳(땅, 발판, 높은 발판)에 아라비아 숫자가 적힌 상자 4개가 있어요.
  - 정답 1개, 오답 3개예요.
  - 오답은 자리를 바꾼 수(12), 몇십(20), 십의 자리만 다른 수(31) 같은 헷갈리는 수예요.
- **들고 오기:** 「📦 들기」로 머리 위에 들고 와서 「🤲 건네주기」를 해요.
  - 틀리면: "이 상자는 20, 二十 이야. 내가 부탁한 건 二十一 이야."라고 알려 주고 상자는 제자리로 돌아가요.
- **3번:** 21 → 35 또는 48 → 62 또는 99
- **힌트:** ① "십의 자리 + 十 + 일의 자리 → 二 + 十 + 一" → ② "二 = 2, 一 = 1 → 21"

### 미션 4 · 숫자 축제 완성 (종합)
축제 촌장 판다의 할 일 4가지를 차례로 해요.
1. 숫자 6~9 중 하나를 중국어로 쓴 **석판(한자)** 찾아 가져오기 (1~10)
2. 입장권 번호 13~19를 **석판 퍼즐로 만들기**
3. 현수막 숫자 60·70·80·90을 **석판 퍼즐로 만들기**
4. 七十三 같은 두 자리 숫자 **상자 찾아오기** (73·56·84·27 중)
- **끝나면:** 앞 미션의 판다 친구들이 광장에 모여 폴짝폴짝 뛰어요. 폭죽과 "숫자 마스터!"가 나온 뒤 숫자의 문이 열려요.

## 4. 화면·조작 원칙 (선생님 요청)
- **평소 화면:** 🏠 홈, ⭐ 미션 진행(0/4), 코인, 📖 배움 노트, 🔊 소리, ❔ 도움말만 보여요.
- **한 줄 안내:** 화면 위에 짧게 나와요. 예) "🌳 사과나무를 흔들어요 (흔든 횟수: 2번)"
- **길 안내:** 가야 할 곳 위에 노란 ▼ 화살표가 떠요. 상자 위치는 정답이 드러나지 않게 표시하지 않아요.
- **상호작용 버튼:** 할 수 있을 때만 화면 아래 가운데에 커다랗게 보여요. PC는 E/Enter도 돼요.
- **미션 창:** ⭐ 미션 버튼 → 「📜 부탁 다시 보기」로 지금 부탁을 다시 볼 수 있어요.
- **소리:** 브라우저 음성(TTS) 품질이 나빠서 **듣기 문제는 없어요.** 🔊 버튼은 참고용이고, 정답 판정에는 쓰지 않아요.
- **그 밖에:** 다른 지역의 스킬(대나무 번개)은 이 지역에서만 숨겨요. 조작 설명을 화면에 길게 띄우지 않아요.

## 5. 보상·기록·저장
- **미션 보상:** 미션마다 코인 +5, 경험치 +20이에요.
  - 처음 한 번만 받아요(`save.questEver.number`에 미션 번호 저장).
  - 홈에 다녀오거나, 새로 고침하거나, 다시 해도 또 받지 않아요.
- **맵의 동전:** 다른 지역처럼 처음 먹을 때만 코인이 돼요. 사과는 코인이 아니에요.
- **판정 문제 수:** 석판 7개(미션2 5개 + 축제 2개)와 운반 5번(배달 3번 + 축제 2번), 모두 12개예요.
  - 처음 시도에 맞히면 "한 번에 맞힘"으로 세요.
  - 결과 화면 별 3개 기준: 클리어 / 한 번에 맞힘 70% 이상 / 동전 25개 이상
- **선생님 시트:** 입장, 미션 완료, 클리어 때 기록을 보내요. 처음 틀린 과제는 "배달: 三十五 상자 → 35"처럼 기록돼요.
- **저장 위치:** 학생 기기의 localStorage예요. 레벨, 코인, 카드, 다른 지역 기록은 그대로 둬요.

## 6. 코드 구조 (한 파일 `src/game.html`, 캔버스 640×360)
- **지역 데이터:** `STAGES.number`에 `quest: true`, `monsters: []`, 미션 4개(label·zone·cards·cheer)가 들어 있어요.
- **미션형 모듈:** 약 500줄이에요. `STAGE.quest`일 때만 돌아요.
  - **숫자 규칙**
    - `zhNum(n)`: 1~99 → `{ h: 한자, p: 병음, toks: [석판 순서] }`
    - `tokVal(toks)`: 석판 순서 → 숫자 (규칙에 안 맞으면 null)
  - **미션 상태**
    - `newQuest()`: 미션별 상태와 무작위 문제를 만들어 `run.q`에 넣어요.
    - `run.q`: 홈에 다녀와도 유지되고, 새로 고침하면 처음부터예요.
  - **상호작용**
    - `questCand()`: 지금 근처에서 할 수 있는 행동(말 걸기·흔들기·석판·들기·건네주기)을 찾아요.
    - `questInteract()`: 그 행동을 실행해요.
    - `questSyncUI()`: 버튼과 한 줄 안내를 바꿔요.
  - **진행**
    - `questGoal()`: 지금 할 일 문장과 ▼ 위치를 정해요.
    - `talkTo(npc)`: NPC별 대화와 진행 상태 기계예요.
    - `judgeDeliver()`: 가져온 물건이 맞는지 판정해요.
    - `questDone(i)`: 보상(처음 한 번)을 주고, 기존 `missionStep → completeMission`(카드·문 열기·선생님 기록)으로 넘겨요.
  - **대화창:** `openTalk / talkHint / closeTalk` (힌트 단계식)
  - **석판 퍼즐:** `openSlab / slabTap / slabCheck / slabUndo / slabHint / closeSlab`
  - **그리기:** `questUpdate(dt)`(사과 물리·줍기·들고 다니기), `drawQuest()`(나무·사과·제단·상자·NPC·▼)
- **공통 엔진에 넣은 곳:** update·render·키 입력·문 막힘 문구·미션 창·스킬 숨김에 `if (STAGE.quest)` 한 줄씩만 넣었어요.
- **예전 5차시:** 몬스터 퀴즈형 원본은 `docs/backup/number-stage-v1.js`에 백업해 두었어요.
- **제약(지켜야 할 것)**
  - 외부 이미지·음악 파일 없이 코드로만 그려요(픽셀 스프라이트, WebAudio 효과음).
  - 서버 없이 정적 페이지로 돌아요(GitHub Pages).
  - 1~4차시의 동작과 기존 저장 데이터를 바꾸지 않아요.

## 7. 테스트한 것 / 못 한 것
- **자동 테스트(Playwright, 56개 항목):** PC 키보드와 모바일 터치 흉내 모두 통과했어요.
  - NPC 대화, 三 번 흔들기 정확 판정, 五 개 정확 수집, 보고해야 완료
  - 석판 정답과 오답 안내, 1~99 한자·병음·순서 전수 검사
  - 상자와 숫자 연결, 미션 전 문 통과 불가, 클리어
  - 새로 고침 뒤 보상 중복 없음, 기존 저장 유지
- 1~4차시 회귀 테스트도 통과했어요.
- **못 한 것:**
  - 실제 학생 플레이 시간 (빠르면 4~5분, 보통 6~9분으로 예상)
  - 실제 휴대폰·태블릿에서의 조작감
  - 아이들 반응

## 8. 알려진 한계 (개선 후보)
- **미션 1은 틀릴 수가 없어요.** 정확히 3번째에 자동으로 떨어지고 5개에서 자동으로 멈춰서, 三·五를 몰라도 진행돼요.
- **방향이 한쪽으로 치우쳐 있어요.**
  - 두 자리 숫자는 "한자 → 아라비아 숫자"(상자 찾기)로만 나와요.
  - 11~90은 "아라비아 숫자 → 한자"(석판 만들기)로만 나와요.
- **힌트 2단계를 누르면 정답이 거의 보여요.**
- **문제 무작위성이 작아요.** 미션 순서와 숫자 범위가 거의 고정이라, 옆 친구 화면을 보고 따라 하기 쉬울 수 있어요.
- **들고 다니는 물건은 한 번에 하나뿐이에요.** 틀린 상자는 자동으로 제자리로 돌아가요.
- **NPC 모습이 단순해요.** 같은 판다 그림에 색과 모자·안경만 다르고, 표정과 몸짓이 없어요.
- **말하기 활동이 없어요.** 따라 말하기는 카드 화면의 안내 문구뿐이에요.

## 9. GPT에게 부탁하고 싶은 것 (예시 질문)
1. 초3~4 첫 중국어 학습자에게 이 미션 순서와 난이도가 알맞은지, 더 나은 단계 구성이 있는지
2. 미션 1을 "몰라도 통과되는" 구조에서 숫자를 실제로 알아야 하는 행동으로 바꾸는 아이디어 (예: 흔든 횟수를 아이가 정해서 보고하기)
3. 두 자리 숫자를 "읽기"와 "만들기" 양방향으로 고르게 연습하는 행동형 미션 아이디어
4. 5~8분 안에서 지루하지 않게 할 보상·연출·변주 아이디어 (억지 대기나 같은 문제 반복은 빼고)
5. 화면이 복잡해지지 않게 하면서 아이들이 길을 잃지 않는 안내 방법
6. 위 코드 구조(`run.q` 상태, `talkTo` 상태 기계, `openSlab` 퍼즐)에 맞춰 바로 넣을 수 있는 구체적인 데이터나 코드 제안

> 제안할 때 지켜 주세요
> - 외부 파일 없이 코드로만 만들어요.
> - 1~4차시를 건드리지 않아요.
> - 듣기 문제로 정답을 판정하지 않아요.
> - 숫자 2의 십의 자리는 二(二十)로 써요.
> - 병음은 글자마다 띄어 써요(shí yī).
