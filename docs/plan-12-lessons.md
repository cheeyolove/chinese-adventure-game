# 판다 탐험대 12차시 확장 계획 (분석 · 제안)

> 이 문서는 **분석과 제안**만 담고 있어요. 게임 코드는 아직 바꾸지 않았어요.
> 선생님이 제공하지 않은 중국어 단어·문장·문제·오답 보기는 만들지 않아요.

---

## 0. 지금 상태 (2026-10, 커밋 기준)

| 지역 | 코드 이름 | 게임 안 표시 | 상태 |
|---|---|---|---|
| 1지역 대나무 언덕 | `bamboo` | 1~2차시 | 학생 공개 |
| 2지역 이름 마을 | `name` | 3차시 | 학생 공개 |
| 3지역 숫자 계곡 | `number` | 숫자 1~10 | 학생 공개 |

**확인이 필요해요.** 말씀하신 "1·3·5차시"는 위 세 지역이라고 이해했어요.
- 대나무 언덕은 지금 화면에 "1~2차시"라고 나와요.
- 숫자 계곡은 "숫자 1~10"이라고 나와요.

1·3·5차시로 표시를 바꿀지 알려 주시면 표시만 고칠게요. 문제 내용은 그대로 둬요.

## 1. 지금 코드가 그대로 쓸 수 있는 것 (재사용 가능)

| 기능 | 새 차시에서 | 이유 |
|---|---|---|
| 지도 배치(발판·문 4개·중간보스·보스 위치) | ✅ 그대로 | `LAYOUT`, `MON_SPOTS`, `GATE_X` 공통 |
| 문 잠금·가운데 통과·클리어 판정 | ✅ 그대로 | 미션 번호만 맞으면 동작 |
| 홈 버튼·이어서 탐험·지역별 진행 보관 | ✅ 그대로 | 지역 id로 따로 보관 |
| 코인(처음 한 번만)·누적 코인 | ✅ 그대로 | `coinsEver`, `dropsEver`가 지역 id별 |
| 경험치·레벨 | ✅ 그대로 | 판다 하나로 공통 |
| 대나무 번개 스킬 | ✅ 그대로 | 이번 탐험(run) 안에서만 동작 |
| 중간보스(2문제)·최종 보스 흐름 | ✅ 그대로 | 문제 목록만 넣으면 됨 |
| 오답 → 힌트 → 보기 다시 섞기 | ✅ 그대로 | 문제마다 `hint`만 있으면 됨 |
| 배경음악·효과음 | ✅ 테마마다 곡 하나 추가 | `SONGS[테마]` |
| 조사 자동 선택(`josa`) | ✅ 그대로 | 단, 새 한자 소리는 아래 2-③ 참고 |
| 저장(localStorage) | ✅ 그대로 | 칸 추가 없이 지역 id만 늘어남 |

정리하면 게임 엔진은 지역 수가 늘어도 대부분 그대로 쓸 수 있어요.

## 2. 고쳐야 하는 곳 (학습 내용 없이도 할 수 있는 공통 구조 정리)

### ① 차시마다 다르게 짜 넣은 코드 → 데이터로 옮기기
지금은 지역마다 특별한 처리가 코드 곳곳에 직접 들어가 있어요.

| 위치 | 지금 | 바꿀 방향 |
|---|---|---|
| 배움 노트 첫 줄 설명 (`s3Intro`) | 이름 마을/숫자 계곡 문장을 코드에 직접 씀 | 차시 데이터의 `noteIntro` |
| 배움 노트 "문장 공식" 상자 (`nameFormula`) | 이름 마을 전용 HTML | 차시 데이터의 선택 항목 `noteExtra` |
| 성조 그래프 화면 (`lessonView: 's1'`) | 1차시 전용 | 그대로 두되, 다른 차시는 공통 카드 화면 |
| 숫자 카드 넓게 보기·클리어 숫자표 | `STAGE.id === 'number'`로 구분 | 데이터의 `cardStyle`, `clearSummary` |
| 마지막 말하기 미션 (`我叫……`) | 이름 마을 전용 문장이 HTML에 있음 | 데이터의 `finale` (말할 문장도 데이터에서) |
| 처음 고르는 지역 (날짜로 정함) | 11/5 날짜를 코드에 직접 씀 | 차시 데이터의 `openDate` |

### ② 차시 공개 상태 관리 (`status`)
```js
status: 'ready'   // 학생에게 공개 (지금 1~3지역)
status: 'draft'   // 준비 중: 학생 화면에 안 나옴, 선생님 미리보기에서만
```
- 학생 화면
  - `draft` 차시는 카드가 아예 보이지 않아요.
  - 주소에 `#지역이름`을 써도 열리지 않아요.
  - 대신 맨 끝에 "🔒 다음 지역 준비 중" 카드 **한 장**만 보여 줘요.
- 선생님 미리보기
  - 주소 끝에 `#preview`를 붙이면 `draft` 차시도 보여요. 화면에 "미리보기(학생에게 안 보임)" 표시가 붙어요.
  - 미리보기에서는 저장에 기록하지 않아서 학생 기록이 섞이지 않아요.
- 공개 방법: 문제를 승인받은 차시의 `status`만 `'ready'`로 바꾸면 돼요.

### ③ 새 한자가 늘어날 때 자동으로 따라가게
- 한자 폰트: 지금은 쓰는 한자를 손으로 적어 둔 목록(`han`)만 내려받아요. 새 차시 한자가 빠지면 다른 폰트로 보여요.
  → 모든 차시 데이터에서 한자를 **자동으로 모아** 내려받게 바꿔요.
- 조사용 한자 소리(`HAN_PY`)도 단어 데이터의 한자·병음에서 자동으로 만들어요.

### ④ 학습 데이터를 파일로 분리
- 지금은 3,200줄짜리 한 파일 안에 단어·문제가 섞여 있어요.
- 차시마다 파일을 하나씩 만들어요: `src/lessons/lesson04.js`처럼. `build.sh`가 한 파일로 합쳐요.
  - GitHub Pages와 Claude 게임 링크 모두 지금처럼 파일 하나로 동작해요.
- 차시 파일 하나에 들어가는 것:
  - 지역 정보(이름·테마·공개 상태)
  - 단어(한자·병음·뜻·성조)
  - 미션 4개
  - 문제 목록(보기·정답·오답·힌트·해설)
  - 중간보스 2문제와 최종 보스 문제
  - 배움 노트 카드
- 새 차시 문제는 **모든 보기를 직접 적는 방식**으로만 받아요.
  - 프로그램이 오답 보기를 자동으로 만드는 방식(지금 숫자 계곡처럼)은 새 차시에 쓰지 않아요.
  - 그래서 승인받지 않은 보기가 나올 수 없어요.

예시 형식 (내용은 비워 둔 틀):
```js
LESSONS.push({
  id: 'lesson04', no: 4, status: 'draft', theme: '(테마)', title: '(지역 이름)', topic: '(배울 내용)',
  words: { /* 'id': { h: '한자', p: '병음', t: 성조, ko: '뜻' } — 수업자료에서 */ },
  missions: [ /* { label, zone, cards: [단어 id] } × 3 + 보스 */ ],
  questions: { /* 미션별 문제: { prompt, show, options: [{ text, correct }], hint, explain } */ },
  mid: [ /* 중간보스 2문제 */ ], boss: [ /* 최종 보스 문제 */ ],
  noteIntro: '(배움 노트 첫 줄)',
});
```

### ⑤ 검사 도구 (게임에 넣기 전 자동 검사)
차시 파일을 넣을 때마다 아래를 자동으로 확인하고 결과를 보여 드려요.
- 문제마다 정답이 정확히 1개인지
- 보기가 겹치지 않는지, 비어 있는 칸이 없는지
- 모든 한자에 병음·뜻이 있는지
- 카드 id가 다른 차시와 겹치지 않는지
- 미션마다 필요한 문제 수(일반 3~4 + 중간보스 2 + 보스)가 모두 있는지
- 조사 검사(`josa`)와 폰트 글자 목록에 빠진 글자가 없는지

### ⑥ 저장 데이터 안전장치
- 이미 받은 동전·몬스터 기록은 지금 "몇 번째 몬스터"로 저장해요. 공개 뒤에 몬스터 순서를 바꾸면 기록이 어긋날 수 있어요.
  → 공개된 차시는 몬스터 배치를 바꾸지 않는 규칙으로 해요(공통 배치를 그대로 쓰면 문제없어요).
- 카드 id는 차시 이름을 앞에 붙여요(`l04_...`). 다른 차시와 겹치지 않게 하기 위해서예요.

## 3. 시작 화면: 지역이 12개로 늘어나도 단순하게

- 학생 화면에는 **공개된 지역만** 보여요. 지금처럼 카드 한 장에 이름, 배울 내용, 별, NEW만 담아요.
- 공개 지역이 6개를 넘으면 카드를 작게(아이콘 + 이름 + 별) 2~3줄 격자로 보여 줘요. 휴대폰에서는 가로로 밀어 넘기는 한 줄로 바꿔요.
- 맨 처음에는 **가장 최근에 공개된 지역**이 골라져 있어요(날짜 대신 `openDate`).
- 준비 중 지역은 "🔒 다음 지역 준비 중" 카드 한 장으로만 보여요. 눌러도 아무것도 하지 않아요.
- 게임 화면 HUD는 지금과 똑같아요. 지역 수가 늘어도 버튼은 늘지 않아요.

## 4. 지역 테마·몬스터 디자인 기획 (학습 내용과 무관한 겉모습만)

- 차시 주제가 정해지지 않았으니 **겉모습 후보만** 제안해요.
- 어느 차시에 어떤 테마를 쓸지는 PPT를 받은 뒤 주제에 맞춰 고를게요.
- 테마 이름과 몬스터 이름에는 중국어를 넣지 않았어요.

| 후보 테마 | 배경 | 일반 몬스터 | 중간보스 | 최종 보스 |
|---|---|---|---|---|
| 봄꽃 정원 | 분홍 꽃나무, 징검다리 연못 | 꽃봉오리, 나비 | 연못 거북 | 꽃잎 여왕 |
| 바닷가 항구 | 파도, 돛단배, 등대 | 조개, 작은 게 | 문어 선장 | 큰 고래 |
| 눈 덮인 산 | 눈 쌓인 소나무, 얼음 다리 | 눈송이, 꼬마 눈사람 | 얼음 펭귄 | 눈보라 곰 |
| 사막 오아시스 | 모래 언덕, 야자수, 낙타 | 선인장, 모래 도마뱀 | 모래 항아리 정령 | 황금 스핑크스 |
| 하늘 구름섬 | 떠 있는 섬, 무지개 | 구름 솜뭉치, 연 | 바람 북 | 천둥 새 |
| 등불 야시장 | 밤 노점, 등불 줄, 불꽃놀이 | 꼬치, 종이 등 | 팽이 도깨비 | 큰 용 등불 |
| 판다 학교 | 교실, 칠판, 운동장 | 분필, 공책 | 시계탑 | 큰 종 |
| 별빛 숲 | 반딧불, 버섯 오솔길 | 반딧불, 부엉이 | 달 토끼 | 별 사슴 |
| 용의 성 (마지막 종합) | 붉은 성벽, 구름 계단 | 기와 조각, 북 | 사자춤 사자 | 황금 용 |

- 모든 테마는 지금처럼 코드로 그린 픽셀 그림으로 만들어요.
  - 일반 몬스터, 중간보스, 최종 보스의 크기와 모양을 서로 다르게 해요.
  - 배경 3겹, 땅, 발판, 문, 마지막 패방 색, 배경음악 1곡을 함께 만들어요.
- 테마 그림은 학습 내용과 상관없어서 미리 만들어 둘 수 있어요. 대신 `draft` 상태라 학생에게는 보이지 않아요.

## 5. 차시 콘텐츠를 받은 뒤의 순서 (승인 절차)

1. **선생님:** 차시 PPT 또는 확정한 학습자료를 주세요.
2. **Claude:** 자료에 있는 단어·문장만으로 **문제 초안 문서**를 만들어요.
   - 단어표(한자·병음·뜻)
   - 미션별 문제와 정답·오답·힌트·해설
   - 중간보스 2문제와 최종 보스 문제
   - 배움 노트 카드
   - 자료에 없는 표현이 필요해 보이면 **따로 "제안" 칸**에 적어요. 승인 전에는 게임에 넣지 않아요.
3. **선생님:** 초안을 확인하고 고칠 점을 알려 주시거나 승인해 주세요.
4. **Claude:** 승인한 내용 그대로 차시 파일을 만들어요.
   - 자동 검사(2-⑤)를 돌려요.
   - `draft` 상태로 올리고, 선생님 미리보기(`#preview`) 링크를 드려요.
5. **선생님:** 미리보기로 직접 플레이해 보세요.
6. **Claude:** 공개해도 된다고 하시면 `status: 'ready'`로 바꿔 학생에게 공개해요.

## 6. 개발 순서 제안 (학습 내용 없이 할 수 있는 것부터)

| 단계 | 내용 | 기존 1~3지역 영향 |
|---|---|---|
| A | 차시 `status`(ready/draft), 학생 화면 숨김, `#preview` 미리보기, "다음 지역 준비 중" 카드 | 화면 변화 거의 없음 (준비 중 카드 한 장 추가) |
| B | 지역별 특별 처리(①)를 데이터로 옮기기, 한자 폰트·조사 소리 자동 수집(③) | 화면·문제 그대로 (회귀 테스트로 확인) |
| C | 차시 파일 분리(④) + 검사 도구(⑤) + 빈 차시 틀 | 1~3지역 문제는 글자 하나 안 바꾸고 파일만 옮김 |
| D | 테마 팩 제작(④의 표에서 고르기) — 그림·배경음악만, `draft` | 없음 |
| E | 차시 콘텐츠 받을 때마다 5번 절차 | 해당 차시만 |

- A~C는 기존 문제·단어를 바꾸지 않아요. 지금 쓰는 자동 테스트(문제 판정, 문, 보스, 코인, 저장, 휴대폰 화면 등 112개)로 전후가 같은지 확인한 다음에 올릴게요.
- A~D 중 어디까지 진행할지 정해 주시면 그 단계만 진행해요.
