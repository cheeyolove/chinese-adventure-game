# 판다 탐험대 (熊猫探险队)

초등학생을 위한 중국어 학습 2D 횡스크롤 RPG 시제품입니다.
판다 주인공이 지역을 탐험하며 몬스터를 만나고, 중국어 퀴즈를 풀어 문을 엽니다.

## 실행 방법
- `index.html` 파일을 크롬/엣지/사파리에서 열면 바로 실행됩니다. (서버, 외부 이미지 필요 없음)
- 모든 그래픽은 코드로 직접 그린 독창적인 픽셀 아트입니다.

## 화면 구성 (단순하게)
- 시작 화면: “어느 지역을 탐험할까?” → 지역 카드(이름 · 배울 내용 · 별 · NEW) → **▶ 탐험 시작** 하나.
  - 작게: 📖 배움 노트, ⚡ 빠른 퀴즈, 왼쪽 위 프로필(Lv · 코인), ⚙ 설정(소리, 조작 방법, 내 기록, 기록 지우기).
  - 진행 중인 탐험이 있으면 “▶ 이어서 탐험”과 “처음부터 새 탐험”이 나옵니다.
- 게임 화면 HUD: 🏠 홈 · ⭐ 미션 2/4 · 🪙 코인 · 📖 · 🔊 · ❔ 만 보입니다.
  - ⭐ 미션을 누르면 미션 목록과 Lv · HP · EXP · 맞힌 문제 · 오늘의 결과가 펼쳐집니다.
- 처음 한 번 그림으로 된 조작 안내가 나오고, 이후에는 ❔ 버튼으로 다시 볼 수 있습니다. PC와 터치 기기 안내가 다릅니다.
- 새 탐험을 시작하면 ‘오늘 배울 말’ 카드가 먼저 나옵니다. 카드를 누르면 소리를 들을 수 있습니다.

## 조작
| PC | 휴대폰 · 태블릿 | 동작 |
|---|---|---|
| ← → | ◀ ▶ 버튼 | 걷기 |
| 스페이스 (또는 ↑) | 점프 버튼 | 점프 |
| 몬스터에 닿기 | 몬스터에 닿기 | 문제 시작 |
| 1 ~ 4 또는 클릭 | 손가락으로 톡 | 답 고르기 |

- 화면에 안 보이는 단축키(PC): H 배움 노트, R 오늘의 결과, G 또는 Esc 홈, M 소리, ↓+스페이스 발판 아래로.

## 🏠 홈 버튼
- 누르면 게임이 멈추고 “홈으로 돌아갈까요?” [계속 플레이] [홈으로 이동]이 나옵니다.
- 홈으로 가면 열린 퀴즈·창·음성이 모두 정리됩니다. 코인·카드·경험치·별은 저장됩니다.
- 탐험 중이던 지역은 위치·잡은 몬스터·열린 문이 그대로 남아서 “이어서 탐험”으로 계속할 수 있습니다. 다른 지역에 다녀와도 그대로입니다.
- 페이지를 새로 열면 지도는 처음부터 시작합니다.

## 지역(차시)

| 지역 | 차시 | 내용 | 모습 | 바로가기 주소 |
|---|---|---|---|---|
| 1지역 대나무 언덕 | 1~2차시 | 4성조, 你好 등 인사, 中国 · 汉语 | 대나무 숲 · 죽순/버섯 · 보스 숲의 수호자 | `index.html#bamboo` |
| 2지역 이름 마을 | 3차시 | 我, 你, 叫, 什么, 名字, 你叫什么名字？, 我叫……。 | 기와지붕 마을 · 등불 · 두루마리/등불 · 보스 붓 대왕 | `index.html#name` |
| 3지역 숫자 계곡 | 숫자 수업 | 一 ~ 十 (1~10) | 수정 동굴 · 수정/석판 · 보스 숫자 골렘 | `index.html#number` |

- 아무것도 안 붙이면 11/5 전에는 대나무 언덕, 11/5부터는 이름 마을이 자동 선택됩니다.

### 세 지역 공통 규칙
- 구역 3개 + 보스. 구역마다 학습 몬스터 4마리를 모두 물리쳐야 그 구역의 문이 열립니다.
  - 문은 하늘 끝까지 막혀 있어 점프로 넘을 수 없습니다. 잠긴 문 팻말에 남은 몬스터 수(×4)가 나옵니다.
- 문을 지날 때(판다 몸 가운데가 문 가운데에 닿을 때) 약 1초 동안 빛·효과음·별과 “길이 열렸다!”가 나옵니다.
  - 마지막 문은 가운데에 닿는 순간 “지역 클리어!”와 함께 클리어됩니다.
- 틀리면 잠깐 빨갛게 표시된 뒤 보기 순서가 다시 섞이고 힌트가 나옵니다. 게임오버는 없습니다.
- 동전은 보너스(결과 화면의 별 1개)일 뿐, 클리어 조건이 아닙니다.

### 중간보스 (지역마다 1마리)
- 2구역(지도 한가운데)의 문지기 자리에 서 있어요. 땅 위에 있고, 둘째 문 바로 앞이라 건너뛸 수 없어요.
- 만나면 “중간보스 등장!” 후 복습 문제 2개를 풀어요. 퀴즈 위에 🛡 1/2 진행도가 보이고, 맞힐 때마다 머리 위 방어막이 하나씩 깨져요.
- 틀리면 기존처럼 힌트 후 다시 도전하고, 게임오버는 없어요. 두 문제를 모두 맞히면 처치되고 2구역 진행도가 1 올라가요(2구역 필수 4 = 일반 3 + 중간보스 1).
- 보상: 문제마다 경험치는 일반과 같아요. 처치 보너스(동전 5개 + 경험치 10)는 지역마다 처음 한 번만 받아요.

| 지역 | 중간보스 | 문제 |
|---|---|---|
| 대나무 언덕 | 대나무 수호 슬라임 (대나무 뿔, 대나무 갑옷 띠) | 성조 1 + 인사 1 |
| 이름 마을 | 마법 두루마리 정령 (옆으로 펼친 두루마리, 반짝이는 글자) | 我/你 1 + 叫/什么/名字 1 |
| 숫자 계곡 | 숫자 수정 골렘 (뾰족한 수정 몸) | 一~三 1 + 四~六 1 (기존 문제 유형) |

### 배경음악
- 지역마다 다른 곡이에요(숲 · 마을 장터 · 수정 동굴). 음악 파일 없이 코드가 직접 연주해요.
- 탐험을 시작하면 나오고, 퀴즈·창이 열리면 작아지고, 중국어 음성이 나올 때는 더 작아져요. 홈 화면이나 결과 화면에서는 멈춰요.
- 🔊 버튼으로 끄면 효과음과 함께 꺼져요. ⚙ 설정에서 배경음악만 따로 끌 수 있어요(저장됨).

### 지역별 내용
- 대나무 언덕
  - 성조 죽순 4마리(1~4성): 성조 문제
  - 인사 버섯 3마리 + 중간보스: 你好 · 你们好 · 老师好 · 同学们好
  - 나라 버섯 4마리: 中国 · 汉语 · 병음 기초
  - 숲의 수호자: 5문제
- 이름 마을
  - 구역 3곳의 문제 후 붓 대왕 4문제
  - 마지막에 “我叫 ○○。”를 직접 소리 내어 말하기
- 숫자 계곡
  - 1구역(一二三) → 2구역(四五六) → 3구역(七八九十) → 숫자 골렘(5문제)
  - 문제 유형: 한자→숫자, 숫자→한자, 병음→한자, 훈음→한자, 다음 숫자, 빠진 숫자, 순서
- 새 지역 추가 방법(개발용)
  - `THEMES`에 테마(하늘·배경·땅·발판·문·몬스터 모양)를 하나 추가합니다.
  - `STAGES`에 지역 데이터를 하나 추가하고, `STAGE_ORDER`에 이름을 넣습니다.
  - 지도 배치(`LAYOUT`, `MON_SPOTS`, `GATE_X`)는 그대로 씁니다.

## 동전과 저장
- 동전은 지역마다 **처음 한 번만** 받습니다.
  - 맵 동전, 몬스터 동전, 보스 동전 모두 해당합니다.
  - 홈 왕복, 새로고침, 처음부터 새 탐험, 다시 하기로는 늘지 않습니다.
- 이미 받은 동전은 흐리게 보이고, 먹으면 +0입니다(별 계산용 개수에는 들어갑니다).
- 빠른 퀴즈는 경험치만 주고 동전은 주지 않습니다.
- 기기에 저장되는 것: 레벨, 경험치, 지금 가진 코인, 지금까지 모은 코인, 카드, 지역별 별, 이미 받은 동전 번호.
  - 기기·브라우저마다 따로 저장되며 다른 기기와 동기화되지 않습니다.
- 저장 기록 지우기: 시작 화면 ⚙ 설정 → 🗑 → 확인 창에서 [네, 지울게요]를 눌러야 지워집니다.
- 코인 상점·꾸미기 설계: `docs/design-shop-bgm.md` (상점은 아직 구현 전, 배경음악은 구현됨)

## 중국어 음성
- 기기에 들어 있는 중국어 음성(SpeechSynthesis)으로 읽습니다. 음성이 없는 기기에서는 “이 기기에서는 중국어 음성을 사용할 수 없어요.” 안내가 나옵니다.
- 재생 코드는 `src/game.html`의 `Voice` 한 곳에 있습니다. 녹음 파일로 바꾸려면 `AUDIO_FILES`에 `'我': 'audio/wo.mp3'`처럼 추가하면 됩니다.

## 파일 구조
- `src/game.html` — 게임 전체 코드 (Claude Artifact로 올리는 원본)
- `index.html` — 브라우저에서 바로 여는 파일 (`./build.sh`로 `src/game.html`에서 생성)
- `build.sh` — `index.html` 생성 스크립트
- `docs/design-shop-bgm.md` — 코인 상점 · 판다 꾸미기 · 지역별 BGM 설계
