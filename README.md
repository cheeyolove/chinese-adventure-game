# 판다 탐험대 (熊猫探险队)

초등학생을 위한 중국어 학습 2D 횡스크롤 RPG 시제품입니다.
판다 주인공이 대나무 언덕을 탐험하며 **성조 젤리**와 **빵빵 만두**를 만나고,
중국어 퀴즈(병음 · 4성조 · 글자 · 뜻)를 풀어 몬스터를 물리칩니다.

## 실행 방법
- `index.html` 파일을 크롬/엣지/사파리에서 열면 바로 실행됩니다. (서버, 외부 이미지 필요 없음)
- 모든 그래픽은 코드로 직접 그린 독창적인 픽셀 아트입니다.

## 조작
| 키 | 동작 |
|---|---|
| ← → | 좌우 이동 |
| 스페이스 (또는 ↑) | 점프 |
| ↓ + 스페이스 | 발판 아래로 내려가기 |
| 1 ~ 4 | 퀴즈 답 고르기 |
| Enter | 퀴즈 후 계속하기 |
| H | 배움 노트 |
| R | 오늘의 결과 |
| G | 지역 선택 |
| M | 소리 켜기/끄기 |

태블릿/휴대폰에서는 화면에 터치 버튼이 나타납니다.

## 지역(차시)

| 지역 | 차시 | 내용 | 바로가기 주소 |
|---|---|---|---|
| 1지역 대나무 언덕 | 1~2차시 (11/3) | 4성조, 你好 등 인사 | `index.html#bamboo` |
| 2지역 이름 마을 | 3차시 (11/5) | 我, 你, 叫, 什么, 名字, 你叫什么名字？, 我叫……。 | `index.html#name` |
| 3지역 숫자 계곡 | 숫자 수업 | 一 二 三 四 五 六 七 八 九 十 (1~10) | `index.html#number` |

- 주소 끝에 `#name`을 붙이면 시작 화면에서 이름 마을이 미리 선택됩니다.
- 아무것도 안 붙이면 11/5 전에는 대나무 언덕, 11/5부터는 이름 마을이 자동 선택됩니다.
- 게임 중에는 `지역 선택 (G)` 버튼으로 시작 화면에 돌아가 지역을 바꿀 수 있습니다.

### 이름 마을 규칙
- 구역마다 필수 학습 몬스터(4마리)를 모두 물리쳐야 다음 문이 열립니다. 문은 하늘 끝까지 막혀 있어 점프로 넘을 수 없습니다.
- 동전은 보너스(결과 화면의 별 1개)일 뿐, 클리어 조건이 아닙니다.
- 틀리면 힌트가 나오고 같은 문제를 다시 고를 수 있습니다. 게임오버는 없습니다.
- 마지막 이름 대왕만두의 4문제를 맞히고, “我叫 ○○。”를 직접 소리 내어 말하면 이름의 문이 열립니다.

### 숫자 계곡 규칙
- 1구역(一二三) → 2구역(四五六) → 3구역(七八九十) → 숫자 대왕만두(5문제). 구역마다 숫자 몬스터 4마리를 모두 물리쳐야 돌문이 열립니다.
- 문제 유형: 한자→숫자, 숫자→한자, 듣기→숫자(음성이 없으면 병음→숫자), 다음 숫자, 빠진 숫자, 헷갈리는 한자, 점 세기, 순서대로 놓기.
- 클리어하면 “숫자 마스터!” 화면에서 一~十을 눌러 병음·숫자·발음을 다시 볼 수 있습니다.
- 숫자 카드(num1~num10)와 클리어 별(number)은 다른 지역과 따로 저장됩니다. 레벨·경험치·누적 코인은 판다 캐릭터 하나로 함께 씁니다.

## 동전과 저장
- 동전은 한 번 먹으면 그 탐험이 끝날 때까지 다시 생기지 않습니다. 다른 지역에 갔다 와도 그대로입니다.
- 동전이 다시 생기는 경우: 클리어한 지역을 ‘한 번 더 하기’로 처음부터 할 때, 또는 페이지를 새로 열었을 때(새 탐험).
- 기기에 저장되는 것: 레벨, 경험치, 누적 코인, 이름 카드, 지역별 클리어 별. 맵 상태(먹은 동전, 물리친 몬스터, 열린 문)는 저장하지 않으므로 페이지를 새로 열면 그 지역을 처음부터 다시 탐험합니다.
- 빠른 퀴즈는 경험치만 주고 동전은 주지 않습니다. 대나무 언덕에서 다시 나타난 몬스터는 동전을 떨어뜨리지 않습니다.

## 중국어 음성
- 기기에 들어 있는 중국어 음성(SpeechSynthesis)으로 읽습니다. 음성이 없는 기기에서는 “이 기기에서는 중국어 음성을 사용할 수 없어요.” 안내가 나옵니다.
- 재생 코드는 `src/game.html`의 `Voice` 한 곳에 있습니다. 녹음 파일로 바꾸려면 `AUDIO_FILES`에 `'我': 'audio/wo.mp3'`처럼 추가하면 됩니다.

## 파일 구조
- `src/game.html` — 게임 전체 코드 (Claude Artifact로 올리는 원본)
- `index.html` — 브라우저에서 바로 여는 파일 (`./build.sh`로 `src/game.html`에서 생성)
- `build.sh` — `index.html` 생성 스크립트
